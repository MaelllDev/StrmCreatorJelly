Strm Creator

Repositório

Cria arquivos .strm nas bibliotecas: escolha a biblioteca, navegue pelas pastas (ou crie uma nova), nomeie e cole o link de stream. Depois de criar, rode um scan da biblioteca para o item aparecer.

Pasta de destino
Escolha uma biblioteca para navegar.
Modo
No modo Série, um link por linha = um episódio (S01E01, S01E02, ...).
