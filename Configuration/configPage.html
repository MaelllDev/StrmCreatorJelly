Repositório

Cria arquivos .strm nas bibliotecas: escolha a biblioteca, navegue pelas pastas (ou crie uma nova), nomeie e cole o link de stream. Modo série com lote de episódios (S01E01, S01E02...).

🚀 Abrir o Strm Creator

A criação acontece em uma página dedicada do plugin (o painel do Jellyfin não executa scripts nas páginas de configuração, então o formulário vive fora dele).

Abrir Strm Creator →

🔑 Configuração da API key (uma vez só)

  1. No menu lateral, abra Chaves da API
  2. Clique em + e dê o nome Strm Creator
  3. Copie a chave gerada
  4. Abra o Strm Creator (botão acima) e cole a chave — ela fica salva só no seu navegador

🔒 A chave dá acesso admin ao servidor — use apenas em dispositivos confiáveis. Para revogar, apague a chave em Chaves da API.

💡 Depois de criar

Rode um scan das bibliotecas (o app tem botão pra isso) para os novos itens .strm aparecerem.
